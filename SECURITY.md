# Security Policy

## Supported Versions

Security fixes are applied to the latest minor release. Consumers should upgrade to the newest available version before reporting behavior already corrected there.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository and include affected versions, configuration, impact, and a minimal reproduction. Maintainers will acknowledge a complete report within five business days and coordinate remediation and disclosure.

Never include production idempotency keys, stored response bodies, credentials, or customer data in a report.
