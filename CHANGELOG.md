# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 0.1.0 - 2026-08-18

### Added

- Atomic idempotency executor with request fingerprinting, TTL, ownership, replay, conflict, and in-progress outcomes.
- Annotation and servlet HTTP boundaries with deterministic duplicate behavior.
- In-memory, Redis Lua, and PostgreSQL storage adapters.
- Spring Boot auto-configuration and Micrometer outcome counters.
- Unit, concurrency, web, proxy, auto-configuration, and Testcontainers coverage.
